คู่มือนี้อธิบาย 3 การทำรายการหลักของโมดูลเครื่องมือ ทำได้จากหน้า "ชนิดเครื่องมือ" → เลือกชนิด → เลือกหน่วย ปุ่มบันทึกรายการทั้งหมดใช้ได้เฉพาะผู้ใช้ระดับ staff/ผู้ดูแลระบบเท่านั้น

1

เบิก-คืนรายวัน

เครื่องมือแต่ละชิ้น (แม้เป็นชนิดเดียวกัน) มีรหัสหน่วยและสถานะของตัวเอง ทำให้ติดตามได้ว่าชิ้นไหนอยู่กับใคร

  1. เปิดเมนู "ชนิดเครื่องมือ" → เลือกชนิดที่ต้องการ → เลือกหน่วยที่สถานะ "พร้อมใช้งาน"
  2. กดปุ่ม เบิก กรอกผู้เบิก, แผนก, กำหนดคืน (ถ้ามี), หมายเหตุ
  3. เมื่อนำเครื่องมือมาคืน ให้กดปุ่ม คืน ที่หน่วยเดิม

ดูรายการที่เกินกำหนดคืนได้ที่เมนู "เกินกำหนดคืน" และดูภาพรวม "เบิกวันนี้ / ครบกำหนดคืนวันนี้" ได้ที่ Dashboard

2

ยืมข้ามแผนก

เครื่องมือแต่ละหน่วยมี "แผนกเจ้าของ" ของตัวเอง (ตั้งตอนเพิ่มหน่วยใหม่ หรือแก้ทีหลังได้ที่หน้ารายละเอียดหน่วย)

  1. เบิกเครื่องมือตามขั้นตอนปกติ (ข้อ 1) แต่เลือก "แผนก" ในฟอร์มเบิกเป็นแผนกของผู้ยืมจริง (ไม่ใช่แผนกเจ้าของ)
  2. ระบบจะขึ้น badge ข้ามแผนก ให้อัตโนมัติเมื่อแผนกผู้เบิกไม่ตรงกับแผนกเจ้าของ

ดูภาพรวมเป็นรายแผนกได้ที่เมนู "สรุปตามแผนก" — แต่ละแผนกจะเห็นทั้งรายการ "ยืมออกให้แผนกอื่น" และ "ยืมมาจากแผนกอื่น"

3

บันทึกการทำ PM / ซ่อมเครื่องมือ

ใช้บันทึกทั้งการซ่อมเมื่อเครื่องมือเสีย และการบำรุงรักษาเชิงป้องกัน (PM) ตามรอบ

  1. เปิดหน้ารายละเอียดหน่วยเครื่องมือ กดปุ่ม บันทึกซ่อมบำรุง
  2. เลือกประเภท "ซ่อม" หรือ "บำรุงรักษาเชิงป้องกัน (PM)", กรอกผู้ดำเนินการ, ค่าใช้จ่าย, รายละเอียด
  3. กรอก "กำหนดครั้งถัดไป" — หรือเว้นว่างไว้ได้ ถ้าตั้ง "ความถี่บำรุงรักษา (วัน)" ของหน่วยนี้ไว้แล้ว (แก้ได้ที่ Django Admin) ระบบจะคำนวณกำหนดครั้งถัดไปให้อัตโนมัติเมื่อเลือกประเภท PM
  4. กด "บันทึก" — ระบบจะอัปเดต "กำหนดบำรุงรักษาครั้งถัดไป" ของหน่วยนี้ให้ทันที

ดูประวัติทั้งหมดได้ที่เมนู "ซ่อมบำรุงเครื่องมือ" และ Dashboard จะแจ้งเตือนหน่วยที่ใกล้ครบกำหนดหรือเกินกำหนดให้อัตโนมัติ
